# オブジェクト分割・中間点追加コマンド追加プラグイン
AviUtl2に、AviUtl無印の「中間点追加・分割時に中間の値を反映する」がオフの時の挙動と同じ分割・中間点追加のコマンドを追加するプラグインです。

追加したコマンドで分割・中間点を追加すると、指定の位置のトラックバーの値に、その地点の値ではなく直後の区間の値を適用します。

### 例 : 0→100の直線移動のものを真ん中で分割した場合
- AviUtl2の分割 : 0→50、50→100
- 追加コマンドの分割 : 0→100、100→100

また、分割時の後ろのオブジェクトのセクション毎のチェックボックスの値に、最初の区間の値ではなくその地点の元々の値を適用します。

これらの操作は、オブジェクトが選択状態(右クリック時、ctrl+ドラッグ中など)ならそのオブジェクト全てに対して適用されます。

オブジェクトが選択状態でないなら、フォーカスされているオブジェクトに対して適用します。

# 追加されるコマンド
## 編集 > プラグイン
### 中間の値を保持せずオブジェクトを分割(編集カーソル位置)
- 編集カーソルがあるフレーム位置でオブジェクトを分割します。
### 中間の値を保持せずオブジェクトを分割(マウスカーソル位置)
- マウスカーソルがあるフレーム位置でオブジェクトを分割します。ショートカットキーに割り当てる想定です。
### 中間の値を保持せずオブジェクトに中間点を追加(編集カーソル位置)
- 編集カーソルがあるフレーム位置に中間点を追加します。
### 中間の値を保持せずオブジェクトに中間点を追加(マウスカーソル位置)
- マウスカーソルがあるフレーム位置に中間点を追加します。ショートカットキーに割り当てる想定です。
